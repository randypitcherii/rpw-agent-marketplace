# Agentic Improvements Report skill

The canonical Omnigent project copy is `projects/omnigent/skills/agentic-improvements-report/assets/`. This published-plugin copy makes the portable reporting procedure available to consumers of `rpw-published`; report requirements are in `references/reporting-contract.md`.

- `SKILL.md` — short procedure and safeguard summary
- `assets/template.html` — blank standalone report template
- `assets/example-report.html` — illustrative cycle comparison with equivalent table
- `references/reporting-contract.md` — detailed evidence, recommendation, and chart rules

The skill intentionally does not define telemetry ingestion or a durable improvement log; see issue #1599 for that separate scope.
